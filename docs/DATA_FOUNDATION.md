# Data Foundation

**Track A = historical research truth. Track B = broker execution reality.**
Son alcances distintos dentro del Data Engine existente, con permisos separados.
Certificar precio histórico no acredita costes XM. Observar quotes demo no acredita
research, fills, comisiones, slippage, ejecución live ni todos los ticks del broker.

XM legacy e HistData permanecen EXPLORATORY_ONLY; cero nueva elegibilidad científica.
No comprar datos por ahora. G3 requiere una ruta demostrable y aprobada; no rescatar
segmentos favorables de fuentes bloqueadas ni inferir timezone desde correlación.

COLLECT ONCE → CERTIFY ONCE → REUSE MANY TIMES.
Reutilizar solo capacidades elegibles con lineage, rango y permisos comprobados.
Preservar originales, multiplicidad, incidentes y rechazos. Sin interpolar ni sustituir
spreads cero. Un hash prueba bytes, no procedencia. Una referencia UTC actual no valida
pasado. El repositorio público contiene código y evidencia agregada segura; RAW,
históricos, holdouts y observaciones privadas siguen fuera de Git.
