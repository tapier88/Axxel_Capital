# VALUE FUNCTION ARCHITECTURE

Research Value prioriza qué incertidumbre investigar. La calidad predictiva ML, calibración, estabilidad y desacuerdo son evidencia del experimento, no Trade Value. Trade Value solo existe cuando una política produce retorno neto tras costes verificables; probabilidades altas sin economía positiva valen cero para promoción. `PROXY_COST` impone un techo `RESEARCH_ONLY`.
