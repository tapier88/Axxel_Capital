# TRADE VALUE

Trade Value es el retorno esperado neto condicionado a una decisión ejecutable, costes completos, estabilidad temporal y riesgo. Probabilidad, accuracy o feature importance aisladas no son Trade Value. En ML se calcula solo sobre predicciones OOF y operaciones que superan los umbrales congelados. Si no hay operaciones, es cero; con costes proxy o slippage ausente no puede justificar promoción.
