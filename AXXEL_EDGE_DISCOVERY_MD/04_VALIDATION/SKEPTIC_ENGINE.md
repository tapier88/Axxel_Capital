# SKEPTIC ENGINE

## Contrato vigente de datos

Skeptic consume la calidad del certificado correspondiente al experimento, no un informe global antiguo. REJECTED/EXPLORATORY_ONLY bloquean investigación; calidad admisible no demuestra edge económico.

Los controles auxiliares ML reentrenan con bloques de labels permutados, features retrasadas siete sesiones y seeds +101/+202. Se reportan sin seleccionar el mejor resultado. La supervivencia exige también el Skeptic común de sesiones y el límite inferior del bootstrap por bloques positivo.

## Sistema integrado: Machine Learning

ML reutiliza el Skeptic de sesiones y bootstrap por bloques. Añade gates de calibración, desacuerdo y desplazamiento de labels siete sesiones, además de estabilidad anual, coste 2x y retirada de mejores operaciones. Sin operaciones, los ataques económicos no demuestran supervivencia; bajo desacuerdo no implica edge.

Protocolo de skeptic engine.

## V1 implementada

Ejecuta winsorization, retirada del mejor y peor 5% de sesiones, concentración temporal, coste 2x cuando aplica, dependencia de pocos outliers, calidad y sensibilidad a gaps. Los controles negativos son además un gate: una señal desplazada o condición arbitraria con efecto comparable invalida el candidato aunque su p ajustado sea pequeño.
